# ferd

A clean live flight map. Single-page web app hosted on GitHub Pages.

- Live aircraft positions from the [OpenSky Network](https://opensky-network.org) (anonymous tier)
- Colour by altitude, smooth movement between refreshes, tap for details, follow, callsign search
- Light and dark map tiles from CARTO / OpenStreetMap

Planned: Cloudflare Worker proxy for authenticated OpenSky and FlightAware AeroAPI, a "My trips" view, then push alerts.
